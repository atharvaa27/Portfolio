# Atharvaa Portfolio

Personal portfolio site for Atharvaa Rane. The project is built with Vite, React, TypeScript, GSAP, and Three.js, with a 3D hero character, animated case studies, certifications, publications, and responsive sections for both local and deployed builds.

## Stack

- React 18
- TypeScript
- Vite
- GSAP
- Three.js
- React Three Fiber
- React Three Drei
- Rapier
- React Icons

## Features

- Animated hero section with 3D character scene
- AI/ML-focused case studies
- Certifications section
- Publications section
- Tools and technologies section
- Resume links and contact section
- Deployable to both Vercel and GitHub Pages

## Development

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Build for GitHub Pages:

```bash
npm run build:pages
```

Preview the production build:

```bash
npm run preview
```

## Deployment

This repo supports both deployment targets:

- Vercel
- GitHub Pages via GitHub Actions

The GitHub Pages workflow is in [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml).
